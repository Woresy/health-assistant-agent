# 食物健康助手：8.26 纵向链路范围与验收

本文档依据 [PRD V2.3 第 7 节 8.26 要求](https://ruiyuan-ai-career-map.vercel.app/food-health-assistant-prd.html#8-26-%E7%AC%AC%E4%B8%80%E6%9D%A1%E7%BA%B5%E5%90%91%E9%93%BE%E8%B7%AF) 固定当天范围。

## 当天目标

完成一条可运行、可测试的手动饮食记录纵向链路：

1. 上传一张 JPG、JPEG 或 PNG 图片。
2. 手动输入食物名称和克重。
3. 从固定示例数据中检索 Top-K 候选。
4. 由用户选择候选。
5. 用确定性公式计算营养估算值。
6. 展示待保存内容及数据来源。
7. 用户明确确认后保存一条 `HealthEvent`。
8. 立即重新读取 JSONL，并展示今日记录和汇总。
9. 用一条无浏览器 E2E 测试覆盖上述核心链路。

图片仅作为输入入口，不进行识别，不写入项目数据目录。

## 当天不做

- 不接入大模型。
- 不要求任何 API Key。
- 不实现 YOLO 或其他图片识别。
- 不实现教练风格、健康建议或医疗建议。
- 不接入完整食物数据集。
- 不实现 water、weight、exercise 的业务流程。
- 不实现多进程写入、云数据库、登录或多用户鉴权。

## 数据边界

示例食物数据为手写占位数据，字段保留数据血缘。来源标记为《中国食物成分表》第 6 版整理仓库，仅供学习，不代表正式数据集。

运行时健康事件写入：

`data/health_events.jsonl`

该文件不得提交到 Git。

上传原图不得复制到 `data/`，不得提交到 Git。

## 验收标准

- Python 3.11+ 可安装固定版本依赖。
- `python app.py` 是唯一启动方式。
- 没有 API Key 时应用正常启动。
- 图片错误具有稳定错误码。
- “西红柿”可以通过别名召回“番茄”。
- 检索顺序为标准名、别名、包含词。
- 找不到食物时返回 `not_found`，不猜测营养值。
- 营养计算严格使用“每 100g 数值 × 克重 ÷ 100”。
- `HealthEvent` 外层字段固定。
- 未确认时拒绝保存。
- 相同 `idempotency_key` 重复提交不新增记录。
- JSONL 一行一个完整事件。
- JSONL 坏行必须报告行号。
- 保存失败时页面不得显示“记录成功”。
- 取消操作不写入半成品。
- E2E 不启动浏览器、不依赖 API Key。
